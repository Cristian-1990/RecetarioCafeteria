# Recetario Digital Cafetería

App web local para consultar recetas de cafetería (café, infusiones y otras) desde tablets, sustituyendo el cuaderno físico.

## Stack

- .NET 10
- Blazor Server
- EF Core + SQLite
- MudBlazor

## Estructura

- `RecetarioCafeteria.Back` — dominio, repositorio, servicio
- `RecetarioCafeteria.Test` — pruebas
- `RecetarioCafeteria.Blazor` — frontend
